# Returns and exchanges

## Return window
Most items can be returned within 30 days of delivery. Electronics have a 15-day return window and must include all accessories and original packaging. The window starts on the delivery date shown on the order page, not the order date.

## Items that cannot be returned
Items marked final sale, gift cards, opened software and personal-care products such as earbuds tips or razors cannot be returned for hygiene and licensing reasons. Customised or engraved items are also non-returnable unless they arrive damaged.

## How to start a return
Start a return from the order page after delivery and choose a reason. We email a prepaid return label within one hour. Pack the item securely with everything that came in the box and drop it at any partner courier point within 7 days of creating the return.

## Exchanges
You can exchange an item for a different size or colour of the same product within the return window. Start an exchange from the order page; the replacement ships as soon as the courier scans your return. Exchanges for a different product are handled as a return plus a new order.

## Return condition and inspection
Returned items are inspected within 2 business days of reaching the warehouse. Items that are used, damaged by the customer or missing parts may receive a partial refund or be sent back. We email you the inspection result either way.
