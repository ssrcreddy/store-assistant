Still no legacy system changes. The AI layers reach the Order, Inventory and Payment APIs only through the tool adapter, which uses the signed-in user's identity. In this project, Express mock APIs stand in for those systems.

Request path

  1. CloudFront passes /api/chat through the load balancer to the orchestrator. The user comes from the demo X-User-Id header.
  2. The PII redactor replaces personal data with placeholders; real values go to the vault.
  3. The response cache answers repeat questions from the same user within 60 seconds.
  4. The intent router uses rules to pick a path: template (no LLM), Haiku or Sonnet.
  5. For Claude routes, the prefetch planner runs predictable read lookups first, which saves a model round.
  6. The agent loop calls Claude with the versioned prompt and tools, for up to 3 tool rounds.
  7. The LLM gateway checks the budget, picks the model, streams the response and meters the cost.
  8. The tool adapter calls the legacy APIs with the user's identity; the policy engine turns cancellations into proposals that need a Confirm click.
  9. The streaming guard checks each piece of text, the output guard checks the full answer and restores placeholders for the owner, and the reply reaches the browser.
